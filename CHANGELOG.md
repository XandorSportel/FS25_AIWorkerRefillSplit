# Changelog

All notable changes to **AI Worker Refill Split** are documented here.

## 1.1.0.0

- Replaced the base-game combined **AI Worker Refill - Fertilizer** option with four independent settings:
  - Solid Fertilizer
  - Liquid Fertilizer
  - Lime
  - Herbicide
- Added persistent storage for all four refill settings.
- Improved compatibility when locating and replacing the base-game fertilizer control.
- Added a custom 512×512 mod icon.
- Updated the mod description and documentation to reflect the four-way split.
- Declared the current release as single-player only until server-authoritative multiplayer synchronization is implemented.

## 1.0.0.1

- Moved **AI Worker Refill - Lime** directly below the base-game fertilizer option.
- Added a fallback placement for compatibility with future menu-layout changes.

## 1.0.0.0

- Initial release.
- Added a separate **AI Worker Refill - Lime** setting.
- Separated lime purchases from the base-game fertilizer refill behavior.
- Added persistent storage for the lime setting.
