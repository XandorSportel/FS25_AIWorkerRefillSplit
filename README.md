# AI Worker Refill Split for Farming Simulator 25

This small script mod replaces the base-game **AI Worker Refill - Fertilizer**
option with separate settings for solid fertilizer, liquid fertilizer, lime,
and herbicide.

After loading a save, open **Settings > Game Settings**. The original combined
row is replaced in-place by four individual refill rows.

All four refill settings are stored in:

`Documents/My Games/FarmingSimulator2025/modSettings/FS25_AIWorkerRefillSplit.xml`

## Installation

1. Go to the [releases](link) page.
2. Download `FS25_AIWorkerRefillSplit.zip` from the latest release.
3. Copy the zip file to your FS25 mods folder. (Replace the existing one if you have previously installed an older version)
